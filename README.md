## Project Overview

Wanderly is a fictional travel and tourism website designed to encourage visitors to explore destinations and plan their next trip.

The website focuses on a clean, modern and responsive user experience across desktop, tablet and mobile devices.

## Features

- Responsive navigation bar
- Mobile navigation menu
- Hero section with call-to-action buttons
- Popular destinations section
- Travel packages section
- Why Choose Us section
- Final travel call-to-action section
- Responsive footer
- Hover effects and transitions
- Smooth scrolling navigation
- Responsive design for desktop, tablet and mobile

## Destinations

The homepage includes four popular destinations:

- Bali
- Dubai
- Maldives
- Switzerland

## Travel Packages
